## Recruiter Offline Application Module (ROAM)

ROAM is an offline asset for RZ. This will allow Recruiters to check up to 10 Applicant
records out from RZ.

##  In order to check records out the 680-3A-E must be completed before check

out. ACE records cannot be checked out.
If no actions have been taken on Applicant records checked out within 10 days, they will be
automatically checked back into RZ. The synchronization (sync) process is automatic upon start
up of ROAM provided there is an internet connection and the application is set for automatic
versus manual. Sync can also be accomplished manually by selecting the Perform Web Sync
link. Whenever a recruiter chooses to exit the application, if the laptop is online and changes have
been , the application will ask the recruiter if they want to sync up.

##  Roam Sync process works whether the internet connection is secure or

unsecure.

Processing a Packet
When the ROAM icon is double clicked the initial screen will show
the checked out records. The screen will be blank if no records have
been checked out from RZ. The Network Status indicator will say
Connected or Disconnected depending on whether the system
detects an internet connection.  ROAM will automatically sync when
opened if an internet connection is detected upon start up. This means that a secure connection
does not have to be established to perform Web Sync.  A Manual Web Sync can be performed
with a secure or unsecure connection.  The Perform Web Sync link when selected will allow
manual synchronization whenever needed.
The ARCA presentation link will open a blank ARCA application.  In the middle top portion of
the screen will display the last time a Web Sync occurred.  Under the Last Update column, the
number of days will display in Black if no action has been taken on record within the last 1-4 days,
Yellow between 5-9 days and Red for 10 days or more.  If the days are Red, they will
automatically check in when synchronization is complete and no actions can be taken in ROAM
on this record. The screen also displays data taken from the record and also shows how much of
the packet has been completed.
There are two hidden features with
ROAM.  This is the access to ARCA on the

into RZ, these notes
