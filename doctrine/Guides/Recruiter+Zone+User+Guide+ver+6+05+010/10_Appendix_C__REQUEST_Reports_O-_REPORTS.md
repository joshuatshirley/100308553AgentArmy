## Appendix C – REQUEST Reports (O- REPORTS)

REQEST Reports are reports that may help in
your recruiting efforts. They provide valuable insight
to be better informed before and during the process
of making a Temporary reservation.
Below are the available reports
•
Annual Program Met: This report will show
all of the MOS’s that have met their
requirements for that fiscal year.   This report
can be used to identify those MOS’s that
may be closed for the FY.  Once you have
entered the criteria click on Create Report.
•
Available Vacancy: This report will show AR
vacancies that are available for enlistment.
You must select the component, MPC, and
commuting distance requirement (regular or
expanded), applicant type, gender, grade,
and zip code.  You can narrow the report by
indicating the CAS indicator code, applicant
training type, job, and /or CMF.  When
completing the criteria screen you will need
to know what zip code is assigned to a unit.
Your AR recruiters should already now what
vacancies are available, but this report may
provide you with additional information about
the vacancy.  Once you have entered the
criteria click on Create Report.
•
Company/Area Reservations:  This report
will show you all of the Company/Area Reservations made within a date range you have
specified. You must select either the Company or RSID and set the date range to get the
information requested. The report is listed by: RSID, Applicants SSN, Applicants Name,
DEP/Enlist Date, Temp Reservation Date, MOS and Recruiters SSN.
•
ENLOC Report: You can review the enlisted locations allowed by MOS.
•
Job Quals Policies: You can review the qualification policies on jobs using this report.
You must enter the Component, MPC, and MOS data on the criteria screen.  You can
narrow the search by entering the additional MOS information. This will assist you with
making sure the applicant meets the basic qualifications for that job.  Once you have
entered the criteria click on Create Report.
•
Pays Job Description:  Report that that provides a detail description of all Pays Jobs
•
Pays Program:  This Report provides a list of Pays jobs in a specific zip code.

•
USAR Vacancy Status: Users can report current AR vacancy information using the
Vacancy Status Report.  A MPC must be entered on the Selection Criteria screen.  Users
may also enter a AR Cmd code, UIC, MOS, facility id, and/or battalion to limit the display to
those vacancies matching the specified criteria.
There are mandatory fields on individual reports that must be completed before the report will
be generated.  These required fields are identified by an asterisk and are displayed in red text.  The
other fields can be completed, but will limit your search parameters.  Anytime you are required to
enter your Office Code you should always-select “Incl. Subord” to review all records within your
station or company.  On the selection criteria screen you will find three buttons.  Their functions are
listed below:
•
Create Report: Generates the report based on entered criteria.
•
Cancel Report: Returns to the main Reports page.
•
Reset Criteria: Sets all criteria to the default values, clearing any entries you made on the
screen.
