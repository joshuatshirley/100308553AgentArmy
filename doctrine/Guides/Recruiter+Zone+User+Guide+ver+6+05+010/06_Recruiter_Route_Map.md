## Recruiter Route Map

Route Map is a tool that allows a recruiter to plan their face-to-face prospecting effort using
the Google Map mapping tool.  By using this feature the recruiter can get turn-by-turn directions
to the individual’s address.  No longer will a recruiter need to use MapQuest to get to a lead’s,
prospect’s, or FS’s home. Route Map allows you to map any record in RZ, or other addresses a
recruiter needs to visit during their prospecting efforts.  This will reduce the recruiter’s windshield
time in trying to locate specific addresses or appointments that need to be conducted.
Route Map allows the recruiter to add up to 25 addresses at one time. Remember that one of
the addresses will be the starting point of the recruiting Center or another address that you
physically enter.  The address must be a complete and valid address.  There is no save function
within Route Map but there is a print feature once the map appears.
Go to Map Link
A new window called Route Map will be found on the My View screen,
however; before you can use this feature you must select the records
which you want to map.  You will want to click on the Add to Map link
once records are displayed from any of the People Overview screens or
from the appointments you have on your calendar.  Under Route Map
there are two links.  The Go to Map link allows the recruiter to display the
map and the selected addresses.  This link will also allow the recruiter to
establish a logical route to each address selected.  The Clear Addresses
link will remove the previously selected addresses and allows the recruiter
to create a new prospecting route.  The Addresses Selected label within
the window will show how many addresses the recruiter has selected.
Add to Map
Before the recruiter can use this link, records must be selected either from the Hot Leads
screen; any of the main links under the People Overview screen; the results of any list created
under the People

Address Mapped
Once the recruiter clicks on the Add to Map link, the link name will change to Address
Mapped.  Within the
Route Map window
the number of
Addresses Selected
will increase as a
recruiter continues
selecting records to
be mapped.  When all
of the addresses to be
mapped have been
selected, click the Go
to Map link in the
Route Map window.
Once you select
Go to Map, the
default screen will
show the addresses
of the records that
were selected in the
Addresses pane and
a map of the area.  It
will map the
addresses in the
sequence shown from
top to bottom.  If no
addresses are
selected, the map will
display the United
States map.
Next to this pane
are 4 address control
arrows. These arrows will move records between the Addresses and Removed Addresses
panes.  The single top and bottom arrows allow the recruiter to remove and/or re-add an address,
while the double arrows will remove all or re-add all of the records.  To remove or re-add an
address, the user will need to click on the address to highlight the record and then select the
appropriate arrow.  To change the route sequence, select the address you want to move in the
Addresses pane and then click the up and down arrows to change the route sequence.  This will
allow the recruiter to create a more efficient route during their prospecting efforts.  As you click
the up or down arrow the addresses will move up or down in the route sequence.  Any time that
you make changes to the route sequence in the Addresses window, the recruiter must click the
Get Directions button to display the new route.
The Add Address pane allows the user to manually label and enter another address.  To add
another address, such as a new starting point, put a name such as “Mall” for Label, and type the
address you desire in the Address block.  Now select Add to enter this address in the
Addresses pane to map later.  Select Cancel if you do not want to add this location.

Get Directions
The Get Directions button will place turn-by-turn directions from your starting point to each
address identified from the Addresses pane.  This is the default view when the Get Directions
button is clicked.
This is called the
Map view.  If you
need to rearrange
the mapped
directions, go back to
the Addresses
window and move
the addresses
around until you have
mapped the quickest
route.
Within the Map
pane are four
buttons: Streetview,
Map, Satellite, and
Hybrid.  The Map
button is the default
map screen that was discussed above.  The Streetview provides the capability to zoom in to see
the actually structures
on the ground such
as a house building.
The Satellite and
Hybrid buttons will
display a different
view of the actual
map.  The Satellite
provides a satellite
view of the area from
above without street
designations while
the Hybrid shows the
major streets and
highways.  Just as
with any mapping
tool, you can use the
arrows on the actual
map to zoom in or out
on the map,
depending on your preference. The Streetview option provides the view  as if riding down the
actual street. The little man that is circled indicates where you are.  Placing the cursor in the
picture and double-clicking, will move to the spot clicked. Selecting Map View will change the
view back to default view.

The Print button
allows you to print
the turn-by-turn
directions with or
without the actual
map.  Once the Print
button is clicked, a
screen will appear
with the turn-by-turn
directions.  If the you
just want the
directions, click the
Print button on this
page.  If you want to
show the actual map,

Once the recruiter clicks the Print button, the Print
window will be displayed to select the printer.  It will
print to the default printer unless another printer is

making the appropriate selections, click the Print
button on this screen.
